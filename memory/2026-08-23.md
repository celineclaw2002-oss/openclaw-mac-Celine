- Researched Turkish non-agriculture subsidy and incentive opportunities for a first-time investor with around `EUR 500k`.
- Main conclusion:
  - the realistic path is not mega-investor programs
  - best fits are `Yatırım Teşvik Belgesi` for light manufacturing or formal tourism capex, Ministry of Trade service-export supports for software/service-export models, and selected `Free Zone` / `TDZ` structures for genuinely export-oriented or R&D-heavy setups
- Official threshold examples captured from `yatirimadestek.gov.tr` Q&A:
  - `7.5 million TL` example for a 4th-region priority investment
  - `15.1 million TL` example for a 1st-region target-investment manufacturing case in Izmir
- Important admin barrier captured:
  - `Yatırım Teşvik Belgesi` applications run through `E-TUYS`
  - requires qualified e-signature, ministry authorization, and `KEP`-based setup
